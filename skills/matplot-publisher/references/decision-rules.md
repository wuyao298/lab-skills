# 决策规则与命令系统

代码是数值唯一源；本文是执行时的规则地图。改阈值/预算去 `decision.py`，改权重映射去 `interpretation.py`。

## 1. 形态 → 权重映射

| 形态 | 权重规则 |
|---|---|
| `pulse_dominated` | 脉冲区 10；过渡带（脉冲前后约 0.5% 总长）8；背景 2 |
| `step_like` | 边沿前后各 1% 区间 9；其余 2 |
| `periodic` | 包络峰 8、谷 4 |
| `random_noise` | 全部 2；用户说“底噪”时尾部 20% 提升到 7 |
| `mixed` | 先按脉冲处理，并触发澄清提问 |

用户意图关键词优先级高于形态规则：

- “峰值 / 过冲 / 幅度精度” → 脉冲区保持 10
- “整体 / 形态 / 时序” → 脉冲区降到 8，背景 4
- “底噪 / 噪声 / 基线” → 尾部 20% 权重 7
- `t=0.5` / `放大 t=…` → 该时间 ±1% 区间权重 9
- `preserve [a:b]` → 该区间权重 10，无损直通

## 2. 权重 → 资源分配

默认总输出 `n_out=100000`。

| 权重 | 策略 | 预算 |
|---|---|---|
| ≥9 | 无损直通 | 100% 保留 |
| 6–8 | 精细 Min-Max / M4 | 剩余预算 40% |
| 3–5 | 标准 Min-Max / M4 | 剩余预算 25% |
| 1–2 | 粗糙 Min-Max / M4 | 剩余预算 10% |
| 0 | 只留首尾各 1 点 | <1% |

区域预算按 `区间长度 × 权重` 加权分配。

## 3. 算法选择

- 权重 ≥9：`lossless`
- 权重 6–8 / 3–5 / 1–2：优先 `tsdownsample.m4`；`periodic` 用 `minmax`；`lttb` 用于形状敏感区域
- 任何专业库失败：降级为内置保守 Min-Max（每箱保留 min/max），并在输出中说明

## 4. 参数自适应

- `chunk_size`：32GB→10M，16GB→5M，8GB→2M，更低→0.5M；可用 `psutil` 自动探测，未安装按 16GB。
- `overlap_ratio`：默认 10%；最大脉冲跨度 > 总长 2% 时提高到 20%。
- `pulse_threshold`：默认 3×MAD；异常点很多时提高到 5×MAD。

## 5. 验证标准

| 指标 | 通过线 |
|---|---|
| 峰值幅度偏差 | <1% |
| 边沿斜率偏差 | <5% |
| 包络重合度 | >99% |
| 压缩率 | 如实报告 |

验证实现于 `validation.py::compute_fidelity`；未达标不禁止出图，但必须先向用户明示 `❌`。

## 6. 用户命令

交互确认阶段支持：

| 命令 | 行为 |
|---|---|
| `确认` / `confirm` / `y` | 进入执行层 |
| `adjust n_out=150000` | 提高预算，回到决策→验证 |
| `adjust threshold=4` | 改脉冲阈值，重新感知→理解→决策→验证 |
| `preserve [a:b]` | 标记区间无损，重新理解→决策→验证 |
| `export_config` | 导出当前方案 YAML |
| `/skip_validation` | 已有预览但显式跳过确认（高风险） |
| `/reuse <profile_id>` | 手动复用档案（CLI 自动匹配时优先询问） |

## 7. 档案匹配

`profiles/*.yaml` 匹配度 ≥0.8 时提示复用。复用 = 加载档案中的 `decision` 直接进入执行层，跳过 ③④。
