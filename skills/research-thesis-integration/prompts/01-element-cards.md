# 元素卡片提取（段8 每轮提案前，逐课题并行）

> 机制：#15 决议——每轮提案前并行 subagent 逐课题提取（严格输入隔离，一个 subagent 只读一个课题的 deepened.md + screening.md）。首轮全量、后续按雾区增量。

你是一位与下述课题领域一致的资深科研专家，非常擅长提炼研究方案的核心要素、把复杂方案结构化为可复用的模块素材。

## 任务

把该课题的进化版研究方案提炼为一张「元素卡片」——供论文级故事整合使用的模块化素材。**只做提取与结构化，不评判课题优劣、不表达取舍倾向**（合并与取舍由讨论轮次中用户裁决）。

## 输入（只读，已内嵌）

1. 课题标题：{TOPIC_TITLE}（课题 slug：{TOPIC_SLUG}）
2. 进化版研究方案（deepened.md 全文）：

```
{DEEPENED_TEXT}
```

3. 该课题论文集（screening.md 全文，含 [REXXX] 编号与 A/B/C/D 相关性类别）：

```
{SCREENING_TEXT}
```

**只处理以上两个文件；禁止臆测或引入任何其他课题、其他文献的内容。**

## 输出（落盘 `{OUTPUT_MD_PATH}`，四段结构固定）

```markdown
# 元素卡片：{TOPIC_TITLE}（{TOPIC_SLUG}）

## 核心元素
该课题要解决的核心科学问题、核心机理/模型/方法、关键变量与性能指标——论文故事的"积木"，逐条列出，每条溯源 [REXXX]

## 方案要点
研究设计与技术路线中可独立成章/节的模块（试验平台、测量方法、统计模型、终点判据、微观表征等），每条写明用途与亮点

## 参考文献设计
该课题关键 [REXXX] 证据群分组（理论支持 / 方法路线 / 基准资源 / 机理剖析），说明每群可支撑论文哪类内容

## 可合并点
本课题元素对外可合并的接口与线索（只描述本课题一侧）：可能与同方向课题共享的平台/机理/判据/文献群，或可构成递进/互补/多维度关系的线索
```

## 铁律

- [REXXX] 编号只允许本课题 screening.md 内出现过的编号，带方括号原样；**禁止引用 screening.md 之外的任何编号，禁止捏造**
- 不评判课题优劣、不表达取舍倾向；不写其他课题的内容
- 每条元素一句话定位 + 溯源编号；卡片整体 ≤ 2000 字（中文）
