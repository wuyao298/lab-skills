# 论文级整合方案起草（段8 thesis_story.md）

> 机制：#15 决议——thesis_story.md = 论文级整合方案：选定主线展开，入选元素合并、串联成完整论文故事，标出课题来源与 [REXXX] 溯源。

你是一位科研写作专家，任务是基于用户选定的总标题与主线，把讨论轮次确认入选的课题元素合并串联成一篇完整的论文故事。

## 任务

基于 thesis_argument.md 选定版（用户选定的总标题与主线）与讨论轮次确认的合并裁决，撰写论文级整合方案。

## 输入（只读）

- `thesis/thesis_argument.md` 选定版（选定总标题 + 选定主线）
- `thesis/cards/` 全部元素卡片
- `thesis/rounds/` 讨论轮次（用户确认的入选 / 支撑 / 暂不纳入裁决）

## 输出（落盘 `thesis/thesis_story.md`，结构固定）

```markdown
# 论文级整合方案

## 选定主线
（用户选定的总标题 + 核心论点/研究主线，从 thesis_argument.md 选定版展开）

## 论文故事
（段落级叙事：这条主线为什么成立、各入选元素如何接力/互补/递进，合并成一个完整故事；
每处元素标（课题：<课题 slug>）与 [REXXX] 溯源）

## 支撑层
（讨论中降为支撑的课题元素声明 + 其支撑用途与溯源）
```

## 铁律

- deepened.md 是提炼前**输入**，不原样充当产物——本文件是元素合并后的新叙事
- 只含讨论确认的入选元素；未被用户确认的元素不写进故事
- [REXXX] 编号库内实测（evidence.csv 命中）；课题来源逐处标注（课题：<slug>）
