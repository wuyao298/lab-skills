# 段8 论文故事整合产物契约

> 定稿：#15（段8 定稿：论文故事整合）。执行 = `scripts/thesis_runner.py`（validate / cards / check）+ 主 agent 减雾讨论循环。
> 锚点：incubation 第5集「从多点突破到系统整合」（提示词5-1）。
> 输入 = 全部课题 deepened.md + screening.md（段6 产物）+ 方向证据 CSV（`directions/<slug>/search/evidence.csv`）；输出 = `directions/<slug>/thesis/` 三产物 + rounds/。

## thesis_argument.md（候选总标题 + 核心论点/研究主线）

| 字段 | 必需 | 内容 |
|---|---|---|
| 候选总标题 | ✓ | ≥2 个人读标题，统领全部子课题（锚 5-1） |
| 核心论点/研究主线 | ✓ | 1 段高度概括陈述 + 统领逻辑（递进/互补/多维度…，逐课题溯源） |
| 用户选定 | 讨论后 | 用户选定的总标题与主线（写回本节，来源 = 轮次记录；未定 = "待定"） |

## thesis_story.md（论文级整合方案）

| 字段 | 必需 | 内容 |
|---|---|---|
| 选定主线 | ✓ | 由 thesis_argument.md 选定版展开 |
| 论文故事 | ✓ | 入选元素合并、串联成完整论文故事（段落级叙事） |
| 课题来源 + 溯源 | ✓ | 每处元素标（课题：<课题 slug>）与 [REXXX] 溯源 |
| 支撑层 | ✓ | 降为支撑的课题元素声明 + 支撑用途 |

## thesis_structure.md（章级结构）

| 字段 | 必需 | 内容 |
|---|---|---|
| 章级结构 | ✓ | 章编号/名称/内容范围/对应课题与实验/证据群 表 |
| 章↔课题/实验映射 | ✓ | 每章 ↔ 课题 slug ↔ 实验单元（显式写出） |
| 章间逻辑 | ✓ | 第N章 → 第N+1章 递进/依赖说明 + 总-分-总骨架 |

## rounds/round_N.md（轮次记录）

| 字段 | 必需 | 内容 |
|---|---|---|
| 用户原话 | ✓ | 每问一条（R{N}Q{M} + 用户裁决原文） |
| 判读 | ✓ | (a) 确认合并 / (b) 改合并 / (c) 加约束 / (d) 追问 / (e) 雾区毕业 |
| 动作 | ✓ | 合并确认 / 改合并 / 约束 / 雾区更新 / 增量重提取 |
| 雾区清单快照 | ✓ | `## 雾区清单（本轮末，M 项）` + FG-NN 条目（问题/影响/现状） |

编号连续；雾区逐轮非增，终态清空（M=0）。

## cards/<课题 slug>.md（元素卡片）

| 字段 | 必需 | 内容 |
|---|---|---|
| 核心元素 | ✓ | 核心问题/机理/模型/变量指标（论文故事的"积木"） |
| 方案要点 | ✓ | 可独立成章/节的模块（平台/测量/模型/判据/表征） |
| 参考文献设计 | ✓ | 关键 [REXXX] 证据群分组（理论/方法/基准/机理） |
| 可合并点 | ✓ | 本课题侧的可合并接口与线索（共用平台/机理/判据、递进互补线索） |

RE 引用格式：`[RE003] 2026 JPD 高重频脉冲下自愈机理`（编号 + 年份 + 期刊 + 一句话定位）。

## RE 合法性（脚本实测）

- 卡片 [REXXX] ⊆ 该课题 screening.md 编号集 ⊆ 方向证据 CSV 编号集
- 三产物 [REXXX] ⊆ 方向证据 CSV 编号集
- 非法 → 喂回重写 ≤2 轮 → 仍非法打 ⚠️ → check 失败

## 人工点

1. 每轮讨论裁决（用户逐项定，最终确定权在用户）
2. 选定总标题/主线
3. 终稿审阅（不满意可要求重生成，段6 先例）

## 联动（下游 / 并行）

- 开题报告文档（5-2/5-3）= 可选拓展，契约留雾（#15）：届时输入 = thesis_argument 选定版 + thesis_story + thesis_structure + 参考文献
- 段9 与段8 互不阻塞（#15→#16 已拆）：故事不定验证范围、验证不改故事骨架
