# 段8 减雾讨论规则

形态 = **轻量减雾讨论**（#15 决议）：grilling 轮次 + 雾区清单 + RE 锚点，**无票桌**（元素合并收敛场景，非候选对决）。**最终确定权在用户**。

## 轮次循环（直至雾区清空）

1. 读现状：全部元素卡片（`thesis/cards/`）+ 雾区清单 + `thesis/rounds/` 历史
2. 提案（三块，逐项溯源 [REXXX]，编号 `scripts/evidence.py --re` 库内实测）：
   - **元素提取与合并**：哪些课题元素合并为论文级模块；合并关系（递进 / 互补 / 多维度 / 共用平台 / 共用文献）与理由
   - **方案合理性裁决**：各课题/模块建议纳入主线 / 降为支撑 / 暂不纳入，各给理由
   - **参考文献与内容设计**：章节级内容设计与证据群 [REXXX] 分配
3. 提问（编号 R{N}Q{M} + 推荐答案，3-5 个，grilling 格式）
4. 判读用户答案：(a) 确认合并 / (b) 改合并（拆、换、收窄）/ (c) 加约束 / (d) 追问 / (e) 雾区新点入清单或毕业
5. 落盘 `round_N.md`（用户原话 + 判读 + 动作 + 雾区清单快照）；雾区涉及课题增量重提取（`cards --topics` 子集）
6. 雾区清空 → 讨论结束；连续两轮未减少 → 提示用户显式收口或延期

## 规则（沿用 #10/#11 先例）

1. **术语 pin**：同名异词停下来请用户定名；契约不并列写未决术语
2. **文献作证据不作裁判**：用户领域判断权重更高；提案判断被推翻时以用户裁决为准并写进轮次记录
3. **RE 锚点铁律**：提案与产物的 [REXXX] 一律 `scripts/evidence.py` 库内实测；不杜撰卡片之外的编号
4. **不问后勤**：时间预算、人手等不问——讨论聚焦"元素怎么合并成故事"
5. **最终确定权在用户**：合并哪些元素、怎么合并、总标题与主线选哪个——每轮用户裁决即定稿

## 雾区清单

未决点记录（随 `rounds/` 落盘），每项 = `- FG-NN：<问题> — <影响> — <现状>`；逐轮减少直至清空。雾区 = 元素合并场景的未决点（如某课题元素并入哪章未定、某机理的统领关系未明）；用户"有点感觉但说不清"的想法也进雾区，清晰后毕业为提案。
