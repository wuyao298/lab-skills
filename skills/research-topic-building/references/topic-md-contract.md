# 课题 MD 契约（段5.6 最终输出）

> 定稿：#12（段5 定稿 v2）。段5 最终输出 = `topics/<策略>-<NN>-<短标题>.md`，3 份报告中每个课题提案一个 MD；段6 默认输入全部课题 MD，深化结束后用户比较择优（段6 契约）。

## 文件命名

`<策略>-<NN>-<短标题>.md`

- 策略前缀：`meta`（3.1 元分析）/ `entry`（3.2 高可行入门）/ `innov`（3.3 结构化创新）；3.4 旁路 = `single`
- NN：两位序号（01 起），按报告内提案顺序，同一策略内连续无缺；`single` 独立编号
- 短标题：论文标题提炼的英文小写短横线 slug（≤5 个实词），去特殊字符

## 文件内容

1. 一级标题 = 论文标题
2. 正文 = 提案全文照录（**策略特有字段全保留**）：
   - meta：机会点类型
   - entry：难度等级【初阶/验证性】
   - innov：启发路径 + 核心思考过程
   - single：创新路径（补全短板/验证机理/拓展边界/响应呼唤）
3. 通用五要素：论文标题 / 核心科学问题 / 研究设计与技术路线 / 预期创新性与价值 / 立论依据（[REXXX]）
4. **来源标注**：来源报告文件名 + 报告内提案序号
5. 提取清单：`topics/_extraction_manifest.md`（文件名 ↔ 来源报告第 N 提案 ↔ 策略）

## RE 锚点校验（check_topics.py check）

- 命名模式 `(meta|entry|innov|single)-\d{2}-[a-z0-9-]+\.md`
- NN 每策略连续无缺
- 立论依据非空且含 [REXXX]
- 每个 [REXXX] 在方向证据 CSV 或全局库中实测存在（证据集之外编号 = 校验失败）

## 数量

三策略共 16-24 个（meta 6-9 + entry 6-9 + innov 4-6）；single 0 或多个（旁路触发）。
