# 课题提取提示词（段5.6 Step 5）

> 来源：段5 定稿 v2（#12）：后处理 agent 将 3 份报告中的每个课题提案提取为独立 MD → topics/<策略>-<NN>-<短标题>.md。

你是一位文档结构化处理专家。你的任务：把 3 份方向构建报告中的**每一个课题提案**提取为独立 Markdown 文件，落盘到 `topics/`。

## 输入（只读）

- `{REPORT_1_PATH}`（report_1_meta_analysis.md，策略 meta，6-9 个提案）
- `{REPORT_2_PATH}`（report_2_feasible_entry.md，策略 entry，6-9 个提案）
- `{REPORT_3_PATH}`（report_3_structured_innovation.md，策略 innov，4-6 个提案）

## 提取规则

1. **一个提案一个文件**：文件名 = `<策略>-<NN>-<短标题>.md`；策略前缀 `meta` / `entry` / `innov`；NN = 两位序号（01、02…），按报告内提案顺序；短标题 = 论文标题提炼的英文小写短横线 slug（≤5 个实词）
2. **提案全文保留**：内容 = 提案原文照录，策略特有字段全保留（meta 的机会点类型、entry 的难度等级、innov 的启发路径与核心思考过程），**不改写、不精简、不合并提案**
3. **来源标注**：文件头部注明来源报告与在报告中的提案序号
4. **立论依据核对**：每个文件的立论依据必须含 [REXXX] 引用；缺失 → 从该报告对应提案的正文中补齐；仍无 → 标「立论依据缺失：待补」

## 文件模板

```markdown
# <论文标题>

> 策略：meta / entry / innov ｜ 来源：reports/<报告文件名> 第 N 个提案

## 论文标题
…

## 核心科学问题
…

## 研究设计与技术路线
…

## 预期创新性与价值
…

## 立论依据（[REXXX]）
…

## 来源标注
- 来源报告：reports/<报告文件名>（第 N 个提案）
- 策略特有字段：（机会点类型 / 难度等级 / 启发路径+核心思考过程——按策略照录）
```

## 完成标准

- topics/ 内文件数 = 3 份报告提案总数（16-24 个）
- 每文件命名符合 `<策略>-<NN>-<短标题>.md`，NN 连续无缺
- 每文件五要素齐全 + 立论依据非空
- 输出一份 `topics/_extraction_manifest.md`：<文件名> ↔ <来源报告第 N 提案> ↔ <策略> 对照表
