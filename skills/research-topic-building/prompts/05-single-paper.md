# 单点突破法增量创新提示词（段5 旁路：3.4）

> 来源：incubation HTML 第3.4集「指令 - 单点突破法增量创新指令」，按段5.6 约束改写：产物同样提取进 topics/（single-<NN>）。

你好，请你扮演一位顶级的科研分析师和敏锐的创新策略家。你的专长是「增量创新」，即从一个已有的、坚实的研究成果中，识别出最高效、最直接的「下一步」研究方向。

我的任务是为你提供一篇具体的科研论文。你的核心任务是：对这篇论文进行「手术刀」式的精细解剖，然后基于你的分析，为我生成 **3~5 个**具有「最小可行创新」特性的研究课题。

## 核心原则：「最小可行创新」

你生成的所有课题都必须严格遵循这一原则：与原论文紧密相连的、逻辑上的自然延伸。通常表现为以下几种形式：

- **补全短板：** 针对原论文方法或结论中明确存在的局限性，提出改进方案
- **验证机理：** 原论文观察到了现象，但机理探讨不足，新课题旨在「打开黑箱」
- **拓展边界：** 将原论文的结论/方法应用到新的、但高度相关的条件下，测试其普适性
- **响应呼唤：** 直接执行原论文作者在「展望」部分建议的未来工作

## 第一步：论文深度解剖（内部完成）

重点思考：核心贡献与方法（最关键创新点、独特研究方法或材料体系）；关键结果与数据（支撑结论的核心数据和性能指标）；论证的「黑箱」（作者对哪些机理或现象「知其然而不知其所以然」）；明确的局限性与展望（作者自己承认的局限、「呼唤」的后续研究）。

## 第二步：生成「最小可行创新」课题提案（3-5 个）

请尝试从不同的创新角度出发。每一个提案都必须严格遵循以下模板：

| 模板部分 | 要求 |
| --- | --- |
| **创新路径** | 明确指出该课题的构思主要源自哪种「最小可行创新」思路：【补全短板】/【验证机理】/【拓展边界】/【响应呼唤】 |
| **论文标题** | 精确、有吸引力、能直接体现与原论文传承关系的题目 |
| **核心科学问题** | 一句话清晰定义要回答的最关键科学问题（对原论文问题的深化或拓展） |
| **研究设计与技术路线** | 分点列出具体、可操作的实验步骤，大量参考原论文的实验方法，只在关键变量上修改或补充 |
| **预期创新性与价值** | 增量创新点在哪里 + 如何为原研究提供关键补充或修正 |
| **立论依据** | **关键部分。** 精确说明课题构思基于原论文的哪一句话、哪个图表或哪个局限性，最好引用原文观点或数据 |
