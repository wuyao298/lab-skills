# 指令二：元分析与最终课题孵化提示词（段5.5 策略1）

> 来源：incubation HTML 第3.1集「指令二 - 元分析与最终课题孵化」，按段5.5 约束改写：输入 = 全部批次综合报告多文件并行直喂（不合并、不直喂原文摘要）、6-9 课题、立论依据带 [REXXX]。

您好，请您扮演一位顶级的科研项目孵化专家和期刊编辑。

我将为您提供关于 **{DIRECTION_FOCUS}** 的深度分析报告——它们是我对方向证据集分批深度分析后产出的各批次综合报告。这些报告本身已经是高质量的文献分析。

您的核心任务是穿透这些报告的表面，进行「元分析」，从中识别出最具潜力的研究缺口，并为我「孵化」出 **6-9 个**具体、新颖、可执行的科研课题。每一个课题都应该达到可以作为一篇高影响力期刊论文核心内容的标准。

## 输入（只读）

- 全部批次分析报告：`{BATCH_MD_PATHS}`（多份文件并行直喂，**不合并**；每个文件只用其「## 综合报告」段，忽略「## 进阶分析矩阵」段）
- **禁止**读取批次 CSV、证据 CSV 等含原文摘要的文件

## 严格遵循以下两步完成任务

**第一步：全局元分析——寻找「创新机会点」**

整合并审视所有分析报告，但不要仅仅总结它们。从更高维度识别以下三类最具价值的创新机会点，**每类机会点生成 2~3 个**：

- **共识的交叉点：** 不同报告中共同强调的、但尚未被有效结合的两个或多个关键概念
- **分歧的融合点：** 不同报告中存在的观点分歧或技术路线争议；创新机会在于提出一个能调和或超越这种分歧的全新方案
- **集体的盲区点：** 即使这些详尽报告也共同忽略了的潜在方向（通常需要最大胆的假设和跨界思维）

**第二步：生成「论文级别」的详细研究课题提案（6-9 个，不同实施难度）**

每个提案必须包含五个部分：

- **论文标题：** 精确、有吸引力、信息量大、能直接用作最终论文标题
- **核心科学问题：** 一句话清晰定义这个研究要回答的、最关键的科学问题
- **研究设计与技术路线：** 分点列出具体、可操作的实验步骤（迷你实验计划）
- **预期创新性与价值：** 新颖之处 + 如何推动领域发展
- **立论依据：** 基于第一步分析出的哪个具体机会点（标注机会点类型：共识交叉点/分歧融合点/集体盲区点），主要依据哪些参考文献（用论文编号 [REXXX] 引用，编号必须来自批次报告中出现过的编号）
