# 前沿重算提示词

每轮讨论结束后，重算讨论桌的前沿状态，供下一轮提问。

## 输入（只读）

- `direction/discussion_board.md`（当前票状态、雾区、否因）
- `direction/rounds/` 全部轮次记录

## 任务

1. **票状态重算**：按最近一轮用户答案更新每张票（锁定 / 强候选 / 中候选 / 降权 / 否因）
2. **雾区检查**：用户本轮有没有"说不清但有点感觉"的想法 → 进雾区；上一轮雾区想法本轮是否变清晰 → 毕业为票
3. **否因检查**：本轮被否的票记否因，不再回桌
4. **前沿输出**：前沿 = 未锁定、未被否、且本轮可回答的问题，按优先级排序，每条附推荐答案

## 硬约束

- 前沿问题聚焦"方向值不值得"，**不涉用户后勤**（时间预算、人手等不问；难度分层只展示不过滤）
- 每轮问题数量以用户不费力为准（推荐 3-5 个，各带推荐答案）
- 重算只依据轮次记录与票桌现状，不引入报告未提的方向
- 不预设报告立场：报告判断只是证据之一，用户领域判断权重更高
