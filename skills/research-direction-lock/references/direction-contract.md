# direction.md 方向契约 schema

| 字段 | 必需 | 内容 |
|---|---|---|
| 方向名 | ✓ | 人读名字，术语已 pin（无未决术语） |
| 定义 | ✓ | 轴心 + 深度（机理深度为核心价值），1 段 |
| 为什么值得 | ✓ | RE 锚点（库内实测）+ 用户领域判断（报告只是证据） |
| 边界 | ✓ | 显式排除项 + 场景锚定 |
| 支撑面 | ✓ | 锁定后文献面显式放宽声明（材料/其他工况文献作支撑） |
| 讨论轨迹 | ✓ | rounds/round_N.md 索引（编号连续） |

RE 引用格式：`[RE003] 2026 JPD 高重频脉冲下自愈机理`（编号 + 年份 + 期刊 + 一句话定位）。
