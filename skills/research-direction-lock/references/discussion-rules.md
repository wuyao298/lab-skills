# 讨论机制规则

形态 = **grilling 轮次 + 前沿重算**（每轮），带轻量元素（候选票桌 / 雾区 / 否因 / RE 锚点）。锁定决策 = G5，人做方向决策。

## 轮次循环（≤5 轮）

1. 重算前沿 = 未锁定、未被否、本轮可回答的问题，各带推荐答案
2. 提问（编号 + 推荐答案，grilling 格式）
3. 判读：(a) 锁定 / (b) 改票（合并、收窄）/ (c) 加约束 / (d) 追问 / (e) 雾区毕业
4. 落盘 round_N.md（用户原话 + 判读 + 动作）；更新讨论桌（票状态、雾区、否因）
5. 第 5 轮后提示锁定或显式延期

锁定 = 写 direction.md（用户逐句确认）→ 讨论结束。

## 五条规则

1. **术语 pin**：锁定前出现同名异词，停下来请用户定名；契约不并列写未决术语
2. **报告作证据不作裁判**：用户领域判断权重更高；报告判断被推翻时，以用户重述为准并写进契约
3. **支撑面字段**：锁定后文献面显式放宽（材料/其他工况文献作支撑），防止下游检索/孵化过度收窄
4. **不问后勤**：时间预算、人手等不问（难度分层只展示不过滤）——讨论聚焦"方向值不值得"
5. **RE 锚点加分**：evidence.py 库内实测引证；用户给出新场景后即时补证据、修正报告判断

## 雾区

用户"有点感觉但说不清"的想法 → 进雾区 → 变清晰才毕业为票（下轮或后续轮）。

## 否因

被否的票记否因（像 out-of-scope），不再回到桌上。
