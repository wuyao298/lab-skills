# research-field-report

领域摸底与文献建库。

- **何时使用：** 陌生领域入门，需要把 Scopus 文献整理成库并看清全景、趋势、空白、可行性与竞争态势。
- **输入：** 领域名称、变体、语义群和排除词；Scopus 凭据经环境变量或外置 .env 提供。
- **产出：** 去重的 literature_db.csv、五类领域报告、期刊分层结果。
- **下一步/决策：** 后续用 research-direction-lock 与用户锁定方向。

从 [SKILL.md](SKILL.md) 开始。执行参数、产物契约和恢复规则见本目录的 `references/`。
